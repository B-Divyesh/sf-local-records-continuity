What the pack adds

Know which records you can recover.

Continuity Pack writes an encrypted pack, a readable manifest, and a receipt. The manifest lists the business, source files, and verification command.

△

Verification limit Verification proves the pack decrypts and its files match. It does not replace a periodic test import into your application.

Three steps

Build, verify, and restore the pack.

  1. 01

    Gather the exports

    Name the files and folders that matter. Required sources fail the run if they disappear.

    [[records]] path = "exports/invoices.csv"
  2. 02

    Encrypt the pack

    Each file gets a SHA-256. The complete pack is authenticated with XChaCha20-Poly1305.

    continuity pack --target /media/offsite
  3. 03

    Check the target pack

    A scheduled check decrypts the pack and compares every file hash. A failed check returns a non-zero exit code and names the problem.

    continuity check --target /media/offsite

Install and run

Build your first recovery pack.

Build from source. Release binaries are not available yet.

01 · Install

Build the command

cargo install --git https://github.com/B-Divyesh/sf-local-records-continuity continuity-pack --locked
02 · Configure

Create the configuration

continuity init
03 · Pack

Pack to an explicit target

continuity pack --target /media/offsite/backups
